Condiciones de venta

Qué compras

Reels en Grande es un pack digital descargable: una skill para Claude Code, un motor para generar vídeos y su documentación. Pago único de 49 € (IVA incluido). Al terminar el pago ves al momento el enlace de descarga.

Qué necesitas aparte

Claude Code (según tu plan de Claude), una cuenta de ElevenLabs para la voz y un ordenador (Windows, Mac o Linux) con Node, Python y ffmpeg. Esos servicios se contratan y se pagan aparte, con sus propias condiciones.

Puedes usar el pack para crear vídeos para tus cuentas y para las de tus clientes, sin límite. No puedes revender, regalar ni publicar el pack ni partes de él. El render usa Remotion, que tiene su propia licencia (gratuita para particulares y empresas de hasta 3 personas).
